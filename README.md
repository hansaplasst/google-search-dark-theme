# Google Search Dark Theme

A lightweight [Tampermonkey](https://www.tampermonkey.net/)/[Greasemonkey](https://www.greasespot.net/) userscript that automatically enables Google Search's dark theme.

## Features

- Automatically switches Google Search to dark mode
- Runs on Google search pages

## Installation
[![Install directly with Tampermonkey](https://img.shields.io/badge/Install-Tampermonkey-00485B?logo=tampermonkey&logoColor=white)](https://greasyfork.org/en/scripts/570302-google-search-dark-theme/code.user.js)

1. Install a userscript manager:
   - [Tampermonkey](https://www.tampermonkey.net/) or 
   - [Greasemonkey](https://www.greasespot.net/)

2. Goto [userscript](https://github.com/hansaplasst/google-search-dark-theme/raw/refs/heads/main/google-search-dark-theme-user.js)

3. Install the script.

4. Open or refresh a Google Search page.

The dark theme should be enabled automatically when the relevant Google interface becomes available.
